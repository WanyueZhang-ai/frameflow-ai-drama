# 项目展示：AI 短剧 Agent 设计与编排

## 项目定位

FrameFlow 面向独立短剧创作者，将自然语言创意转为可审核、可追溯、可恢复的视听创作流程。目标不是单次生成一段文本，而是把不同模态工具组织成协作流水线，并让创作者在关键节点保有控制权。

## 问题与方案

| 创作问题 | 设计方案 | 代码落点 |
| --- | --- | --- |
| 一个长提示词难以控制全流程 | 专职 Agent + 显式任务依赖 | `dist/lib/engine.mjs` 中 `AGENTS`、`step`、`start` |
| 剧本、画面之间的人设漂移 | 角色设定结构化，持续传递风格与故事事实 | `run.memory`、`demoBoard`、`llm` |
| 视频生成耗时且不稳定 | 异步任务轮询、幂等键、检查点恢复 | `src/providers.mjs` 的 `video` |
| 视频和声音互相等待 | 二者并行，合成等待双方完成 | `Promise.allSettled` |
| 模型 JSON 字段缺漏 | 显式产物验证，定向修复一次 | `validateArtifact`、`llm` |
| 修改上游后旧成片仍存在 | 定向失效依赖产物 | `dist/app.mjs` 的 `invalidate` |
| 用户看不到工具执行过程 | 状态、耗时、调用事件、阶段产物 | 右侧协作面板和全部记录 |
| 未审查就消耗生成额度 | 可选分镜人工确认闸门 | `awaiting_review`、`approved` |

## 设计细节

Agent 是角色、职责、上下文、工具和输出协议的组合。当前实现采用中央编排器协调专职 Agent；其协作通过结构化产物和共享记忆完成。没有把多个可视化名字误称为独立自治的群体对话系统。

制片 Agent 的规划结果作为后续上下文；任务图在工程中固定，保证依赖和审批可验证。它不会动态增加节点或执行任意模型生成代码。此设计用可控性换取有限的规划自由度，适合首版工程原型。

记忆分为角色设定、风格约束、情节事实和阶段摘要。前一任务完成后写入记忆，后续任务读取统一快照。它不是向量数据库，也没有跨项目检索；当前故事规模有限，因此采用明确可检查的结构化上下文。

MLLM 的入口是导演阶段的参考图：前端上传受限类型与大小的图片，服务端在视觉支持的 Chat Completions 请求中传入 `image_url`，结合剧本和角色记忆规划镜头。视频适配器也可以接收参考图。实际角色身份连续性仍依赖供应商模型，提示词约束不能保证像素级一致。

工具输出先验证，再完成状态迁移；瞬时请求失败可重试，业务错误直接停止。视频和声音独立分支用 `allSettled` 收集结果，即使一个失败，也保留另一个已经完成的结果。停止操作通过 `AbortController` 传播到等待、网络请求及媒体子进程；不会删除完成的产物。停止本地轮询并不代表已取消供应商端的视频任务，该任务 ID 会保留。

## 五分钟展示路线

1. **0:00–0:40，作品入口。** 打开工作台，说明目标用户和完整流程，展示预制「雨夜便利店」项目。先明确演示产物来源。
2. **0:40–1:30，创作输入。** 编辑简报的类型、风格、画幅、时长，说明参考图如何进入 MLLM，展示人工确认开关。
3. **1:30–2:30，实际编排。** 点击重新运行，观察任务按依赖推进。到分镜审批时，打开镜头提示词，展示角色外观如何来自项目记忆。
4. **2:30–3:20，人机协同。** 修改镜头提示词，确认继续。展示视频与声音分支并行，再进入合成。切到全部记录，指出真实执行事件。
5. **3:20–4:10，产物交付。** 播放动态分镜，开启朗读，导出 SRT、剧本和完整 JSON。说明真实模式会交付服务端合成的 MP4。
6. **4:10–5:00，工程说明。** 展示 Agent 编排与项目记忆页，说明检查点、错误重试、上游编辑失效、真实接口配置和原型边界。

## 验收方式与指标

工程验收使用可重复行为测试，不使用未经测量的“效率提升”数据。关键检查包括依赖顺序、并发成立、审批前下游调用为零、恢复不重复上游任务、审稿失败隔离、结构化校验、工具检查点和瞬时错误重试。

真实模型质量评估应另行构建固定创意集和人物连续性标注，分别统计剧本遵从性、逻辑冲突率、跨镜头一致性、配音可懂度、时间轴误差、任务成功率、总耗时与真实费用。当前未进行此类真实模型基准，不提供虚构成绩。

## 可以如何继续扩展

先接入一个真实视频服务并记录 10–20 个固定故事的端到端结果，再根据失败样本补充审稿修订循环、镜头重生成和人设视觉参考。随后添加队列、对象存储、费用上限与按用户隔离。只有在项目数量增长且上下文超过模型窗口时，再引入长期记忆检索。
